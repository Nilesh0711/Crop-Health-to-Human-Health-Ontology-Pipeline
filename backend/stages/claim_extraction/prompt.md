# TASK
Extract direct, atomic, observed scientific findings within the ACTIVE APPLICATION SCOPE below. Return {"claims": []} when none exist. Study aims, methods, table/figure titles and bare laboratory markers are not findings.

# RULES
1. **Target and evidence.** Extract only findings stated in target sentences. Reading-context sentences may be cited in evidence_sentence_ids only to resolve a pronoun or local referent ("this cultivar", "its translocation"). Never invent or renumber IDs.
2. **Self-contained endpoints.** subject and object are single concepts, copied with the source wording and abbreviations. Keep the defining organ, state, deficiency, treatment or event inside the endpoint ("root phosphorus concentration", "limited phosphorus availability", "Bacillus subtilis inoculation"). Never reduce a state to its bare substance. Never use a bare treatment code ("P0.5"), a bare study factor ("cultivar", "interaction") or a control label ("non-inoculated plants") as an endpoint: write the biological entity or exposure it stands for ("low phosphorus supply (P0.5)"), and put control groups in qualifiers.comparator. Split bundled lists ("X and Y") into separate claims, repeating shared words.
3. **subject and object must differ.** Never emit the same string on both sides. For a comparison, make the compared item the subject or object and put the baseline in qualifiers.comparator (e.g. subject "Cultivar A", relation "has higher shoot phosphorus concentration than", object "Cultivar B"; or subject "Treatment T", relation "increases", object "Trait Q", comparator "untreated control").
4. **Preserve polarity, hedging and restrictions.** Keep negation ("does not increase", "cannot acquire"), non-significance ("did not significantly affect"), hedging ("may promote") and restrictive quantifiers ("only 1 of 22 traits") in relation, endpoint or qualifiers.metric. A non-significant change is not an established effect. If no faithful triple exists, omit the claim. Never turn A→B→C into A→C and never invent causation.
5. **relation** is one standalone predicate (verb phrase) with no numbers, cultivar names or endpoint adjectives. Put percentages and magnitudes in qualifiers.metric ("decreases" + metric "over 40%", never "causes a decline of over 40% in") and never end a relation with a dangling "than" or "to". Keep source direction for passive clauses.
6. **Qualifiers** (all optional strings; omit unused keys): crop_or_species, population (cultivar, genotype, stage, organ bearer), condition (treatment, supply level, environment), comparator (baseline or compared group), metric (values, units, significance, quantifier).
7. **Anchors.** subject_anchor and object_anchor are the shortest exact text spans copied from the cited sentences that name the subject and object.

# OUTPUT
Fields: subject, object, relation, qualifiers, evidence_sentence_ids (required); subject_anchor, object_anchor (strongly recommended). No other keys, summaries, reasons, confidence or ontology IDs.
