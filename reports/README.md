# Developer reports

Store ad hoc extraction audits, benchmark exports and evaluation samples here.
Report data is ignored by Git; this guide is tracked. Application run artifacts
remain in `ontology/<PDF stem>/`, and standalone CLI working files remain in
`reports/external_validation/`. Keep source code and documentation out of generated report folders.

The reusable packet comparison tools and protocol are documented in
[`scripts/research/packet_comparison/README.md`](../scripts/research/packet_comparison/README.md).
Their prepared source snapshots, request metrics, provider responses and source-review
records live in a dated report folder. Model judgements are provisional source-fidelity
checks, not expert gold annotations.
